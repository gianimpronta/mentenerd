# Desempenho dos Shorts

Cada arquivo `AAAA-MM-DD_HHMM.csv` é um retrato das views no Studio naquele momento, para comparar depois.

- `2026-10-31_1144.csv`: views antes da mudança de títulos (títulos com maiúsculas nas primeiras palavras, feita em 2026-10-31). A coluna `titulo_antes_da_mudanca` guarda o título original.
- Retenção (% médio assistido) vem do Analytics (28 dias até 29/out) e só existe para parte dos vídeos.
- Visão geral do canal em 2026-10-29 (28 dias): 32,4 mil views, 132 h de exibição, +35 inscritos; ~93% das views vêm do feed de Shorts.
